# Krishna K P - Senior Software Engineer Portfolio

A modern, high-performance, responsive single-page portfolio website designed and developed for **Krishna K P**, Senior Software Engineer with 9+ years of experience across .NET Core, Angular, Microservices, AWS, and SQL Server.

## 🚀 Features

- **Single Page Architecture with 5 Core Sections:**
  1. **Home / Hero:** High-impact introduction, actual professional photograph, headline, core tech badges, and dual CTAs (*View My Projects* & *Download Resume*).
  2. **About Me:** 9+ years career narrative, enterprise domain experience (Banking, Healthcare, Government, Education), MCA degree (CGPA 8.54), certifications, and languages.
  3. **Skills & Technologies:** Categorized by CV data (Backend, Frontend, Cloud & DevOps, Databases, Architecture & QA, and AI & Modern Tooling) with interactive filter tabs.
  4. **Experience & Projects:** Employment history (Mphasis, Qualifacts, Cyspan, NexGen, Speridian, NIC) with vertical timeline and featured enterprise project cards.
  5. **Contact Me:** Direct email, phone, location, and a validated contact form that prepares messages directly for Krishna's inbox.
- **Sticky Glassmorphic Navbar:** Smooth scrolling, active section tracking, mobile drawer navigation, and resume download action.
- **Dark Theme UI/UX:** Built with Tailwind CSS using a deep navy/slate color palette, glowing cyan/blue accents, and sleek hover effects.
- **Strict CV Accuracy:** 100% grounded in Krishna's real CV with zero placeholder or fictitious data.

## 🛠️ Tech Stack

- **React 18**
- **Vite 5**
- **Tailwind CSS 3**
- **Lucide React Icons**
- **Framer Motion**

## 🏃 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
